# 河谷初生 0.1

独立的轻量村落经营原型。玩家版为 `河谷初生.html`，完全包含样式、图案和程序，不依赖 CDN、服务器或外部素材。

## 打开游戏

将下载的 ZIP 全部解压，双击 `河谷初生.html`，用 Edge、Chrome 或 Firefox 打开。具体操作见 [开始游戏说明.txt](开始游戏说明.txt)。

首局 5 人，初始食物 18、木材 10、石料 6。初始分工：采食 2、伐木 1、采石 1、建造 1。每人每天消耗 1 食物；建造者推进工地，不产出材料。

20 天内达成全部条件即胜利：10 人、足够床位、至少一座农圃和一座仓库、两天储粮、每日食物净变化不为负。第 20 天结算也可以获胜；无人留下或到期未达标则失败。

新居民每三天到来一次，要求空床位、两天储粮并且当日不缺粮，抵达时领取 2 食物。农圃在建成后的第二天开始提高产量；新居民下一天开始正常吃饭。连续两天缺粮，一人离开。

### 建筑

| 建筑 | 木材 / 石料 | 工作量 | 效果 |
| --- | --- | --- | --- |
| 木屋 | 8 / 3 | 2 | +3 床位，最多 4 座 |
| 农圃 | 10 / 4 | 3 | 每名采食者每日 +1 食物，最多 2 座 |
| 仓库 | 12 / 6 | 3 | 每种资源容量 +50，最多 2 座 |

工地同时只能有一个，开工立即扣材料。取消返还材料，受当前仓储容量限制。初始每种资源最多储存 30，第一座仓库提升到 80。

## 存档

每次调整工作、建造和每日结算自动写入浏览器 localStorage。浏览器限制本地存储时会提示使用导出存档。移动 HTML、更换浏览器、隐私模式和清理浏览器数据可能影响自动存档，因此建议导出 JSON。导入有数据校验和覆盖确认。离线不计算进度，重新打开后时间暂停，日内计时会重置。

## 开发结构

- `model.js`：无界面副作用的资源、工作、建造、人口、胜负与存档校验模型。
- `game.js`：界面、输入、每日计时、自动保存与导入导出。
- `index.html` / `style.css`：开发用页面。可直接打开，也可用本地静态服务器。
- `河谷初生.html`：由源码生成的单文件玩家版。
- `tools/package.py`：仅用 Python 标准库生成单文件和独立 ZIP。
- `tests/model.test.cjs`：Node 内置测试，无第三方依赖。
- `tests/browser.test.cjs`：Playwright 浏览器流程检查；开发环境需已有 Playwright 和 Chromium。

更新源码后执行：

```bash
python3 village-game/tools/package.py
node --test village-game/tests/model.test.cjs
```

云端浏览器测试：

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory village-game
# 在另一个终端执行：
GAME_TEST_URL='http://127.0.0.1:8765/%E6%B2%B3%E8%B0%B7%E5%88%9D%E7%94%9F.html' node village-game/tests/browser.test.cjs
```

`CHROMIUM_PATH` 可指定 Chromium 路径，默认 `/usr/bin/chromium`。本地服务器仅供开发验证，玩家无需运行。详细结果见 [VALIDATION.md](VALIDATION.md)。

## 当前范围

这是完整小循环的原型，内容固定，没有随机地图、声音、角色动画、居民寻路、天赋继承、战争和多人。平衡验证包含一条第 15 天可获胜的正常策略，不代表所有分配方式都能成功。
