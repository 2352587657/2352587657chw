# 明亮写实历史风素材

这些图片由本项目生成，参考已选定的 D 明亮写实历史概念方向，不是实际 3D 模型。

- historical-sprites.png：透明背景的 3 列 × 2 行精灵图集。上排依次为营地、木屋、仓库；下排依次为农圃、树木、石头。地图采用源矩形绘制，树木帧的左边缘排除少量相邻围栏。
- historical-terrain.png：2 列 × 2 行地面纹理。上排草地、泥土；下排河水、岩石。运行时使用纹理区域创建重复图案。

源图不改写，渲染时控制缩放、草地色调和透明度。玩家版由 tools/package.py 将两张图片以 data URI 嵌入 HTML，不需要单独下载素材。

目前仍有重复树木、地块式河岸和贴图视角差异，后续可以继续调整；不代表已实现完整 3D 地形、人物动画或村民寻路。
