# 0.3 验证记录

环境：Godot 4.6.3，Linux 云环境；Xorg 虚拟显示、Mesa llvmpipe 软件渲染。

## 自动冒烟检查

执行 `godot --headless --path . -- --smoke-test`：58 项检查，0 失败，退出码 0。

- 开局空背包，36 个物品格；每叠上限 9。
- 加入 20 份纤维会分成 9 / 9 / 2；右键拆半、左键合并正常。
- 500 次随机拆分、合并和交换操作，所有物品总数保持不变，各堆叠数量始终合法。
- 实际生成的两株纤维植物，通过玩家瞄准和鼠标挖掘路径采集，不能重复采集。
- 左右键把纤维放入两格手工区，点击输出，消耗两份纤维并产出一根粗绳；材料不足不能再次制作。
- 满背包合成会落地；已有粗绳堆叠优先接收；关闭背包不会丢失手上与手工区材料。
- Q 单个、Ctrl+Q 整叠、长按不重复、菜单不丢弃。
- 地面掉落冷却后可以拾取；只剩一个容量时，剩余物品继续留在地上。
- 小石头、枯枝、普通草都可采集；挖地获得方块，放置扣一个，无效放置不扣材料。
- 区块远离卸载、返回重载后保留方块修改和植物采集记录，NPC 对话可用。
- 保留两个相邻方块合并为六个外表面矩形的检查。

## 实际图形输入检查

`tests/gui_input.gd` 通过 Godot 的真实输入事件队列操作，而不是直接修改背包数据：

- 鼠标左键采集两株植物。
- B 打开背包，左键拿起纤维，右键拆出一个，再左键放入另一格。
- 点击成品按钮进行合成。
- 鼠标悬停快捷格按 Q 丢出一根粗绳。
- 在背包背景按 Q 无效；成品预览不能用 Q 丢出。
- B 关闭背包并恢复玩家控制。

检查菜单、游戏和背包布局，截图见 screenshots/。图形输入测试应输出 failures=0。
